# Screenshot halaman

Simpan screenshot aktual dari kelima halaman setelah menjalankan aplikasi, lalu letakkan di `docs/screenshots/` dengan nama berikut:
- `home.png` - halaman Beranda (`/`)
- `about.png` - halaman Tentang (`/about`)
- `services.png` - halaman Layanan (`/services`)
- `portfolio.png` - halaman Portofolio (`/portfolio`)
- `contact.png` - halaman Kontak (`/contact`)

README ini menyiapkan daftar screenshot yang dibutuhkan. Screenshot aktual belum disertakan karena perlu diambil dari aplikasi yang sudah dijalankan pada browser.

Buka tiap route saat `npm run dev` berjalan, atur browser pada ukuran desktop, ambil screenshot, dan letakkan file PNG di folder ini. Tambahkan juga tampilan mobile bila diminta asisten praktikum.
